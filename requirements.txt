# RUNTIME REQUIREMENTS

Node.js       >= 18.x   (https://nodejs.org)
npm           >= 9.x    (bundled with Node.js)
MongoDB Atlas account   (https://www.mongodb.com/atlas)


# ------------------------------------------------------------
# INSTALLATION
# ------------------------------------------------------------
# 1. Clone / download the project folder
# 2. Open a terminal in the project root
# 3. Run:
#       npm install
# 4. Create a .env.local file (see Environment Variables below)
# 5. Start the development server:
#       npm run dev
# 6. Open http://localhost:3000 in your browser

# ------------------------------------------------------------
# EXTERNAL SERVICES REQUIRED
# ------------------------------------------------------------

# 1. MongoDB Atlas
#    - Create a free cluster at https://www.mongodb.com/atlas
#    - Whitelist your IP and get the connection string
#    - Used for: all data (leads, clients, projects, tickets,
#                job postings, job applications)

# 2. Cohere API  (https://cohere.com)
#    - Free tier available
#    - Used for: generating text embeddings for the RAG chatbot

# 3. Groq API  (https://console.groq.com)
#    - Free tier available
#    - Model used: llama-3.3-70b-versatile
#    - Used for: LLM inference in the RAG chatbot

# 4. Gmail Account with App Password
#    - Enable 2-Factor Authentication on a Gmail account
#    - Generate an App Password at:
#      https://myaccount.google.com/apppasswords
#    - Used for: sending job application status emails
